# Phase 01 — Foundations and Engineering Mindset

## Goal

Build a strong software engineering base before applying AI concepts in production.

## What to Learn

- JavaScript or TypeScript fundamentals
- Backend basics with Node.js and APIs
- Databases such as PostgreSQL and MongoDB
- Authentication, REST, and basic system design
- Git, GitHub, and professional developer workflows

## Why It Matters

AI features only become valuable when they are built on a solid engineering foundation. A professional developer must know how to structure applications, manage data, and deploy reliable systems.

## Focus Areas

- Clean code and modular architecture
- API design and data flow
- Error handling and debugging
- Version control and collaboration

## Mini Project

Create a small full-stack app with:

- user authentication
- CRUD operations
- a backend API
- a frontend interface

This will prepare you for future AI integration.

## Key Topics

- Software engineering foundations
- APIs, databases, and backend basics
- Git and professional workflow
- Problem framing for AI-enabled product development

## Learning Objectives

- Build a stable software engineering base
- Understand how web applications are structured
- Prepare for AI integration with strong fundamentals

## Projects

- Create a small CRUD web app
- Add authentication and database persistence
- Build a simple backend API

## Resources

- JavaScript/TypeScript documentation
- Node.js and Express guides
- PostgreSQL and MongoDB basics
- Git and GitHub workflow tutorials

## Outcome

You should be able to build normal web applications confidently before adding AI features.
