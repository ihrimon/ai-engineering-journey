# Phase 03 — AI API Integration

## Goal

Connect AI services to applications through APIs.

## Topics to Learn

- OpenAI API
- Anthropic API
- Google Gemini API
- Streaming responses
- Error handling and retries
- Token usage and cost awareness

## Practical Skills

- call an LLM from Node.js or Next.js
- handle streaming UI updates
- manage API keys securely
- implement fallback strategies

## Mini Project

Build a chatbot that:

- accepts user input
- sends it to an LLM provider
- returns a response in the UI
- handles errors gracefully

## Key Topics

- OpenAI, Anthropic, and Gemini APIs
- Streaming responses
- Error handling and retry logic
- API key security and cost awareness
- Model integration in web apps

## Learning Objectives

- Connect LLM providers to applications
- Handle real-world API errors and retries
- Understand cost, limits, and model selection

## Projects

- Build a chat app powered by an LLM API
- Add streaming responses to the UI
- Implement fallback logic for failures
