# Phase 05 — RAG and Knowledge Systems

## Goal

Teach AI systems to answer questions using your own data.

## Core Concepts

- embeddings
- chunking
- vector search
- metadata filtering
- retrieval and context injection

## Why RAG Matters

LLMs alone are limited by training data and context size. RAG allows them to use documents, FAQs, and internal content to provide grounded answers.

## Topics to Learn

- text splitting strategies
- similarity search
- vector databases such as pgvector, Chroma, or Qdrant
- document ingestion pipelines

## Mini Project

Build a document Q&A assistant that can:

- upload PDFs or text files
- split them into chunks
- create embeddings
- retrieve relevant context
- answer user questions

## Key Topics

- Embedding generation
- Chunking and indexing
- Vector search and similarity search
- RAG pipeline design
- Vector databases and hybrid search

## Learning Objectives

- Understand how RAG improves LLM answers
- Learn document ingestion and retrieval patterns
- Build knowledge-based assistants using your own data

## Projects

- Build a document Q&A app
- Index PDF or text files into a retrieval system
- Add semantic search to an assistant

## Resources

- RAG tutorials and architecture guides
- Chroma, Qdrant, and pgvector docs
- LangChain and LlamaIndex examples
- Embedding model documentation

## Outcome

You should be able to build knowledge assistants that are more useful than generic chatbots.
